One Wi-Fi network name that tells a whole story:

> FreeWiFiIfYouWaterMyPlants

A neighbour goes away and offers free Wi-Fi to whoever waters their plants. The trip, the bargain, and the plants left behind all land on the last word. Nothing is explained — the reader fills in the empty flat and the watering can.

## Run it

```sh
node main.ts
```

Writes exactly `FreeWiFiIfYouWaterMyPlants` (26 bytes, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
